Import data… ไฟล์ใหม่

เดี๋ยวเราจะลองไปดูกันว่า หากกดด้วย ADANCO จะต้องทำยังไงบ้าง ครั้งนี้มีงานใน Excel คั่นกลางด้วย ข้อแรก รันโมเดลหลักก่อน แล้ว Export คะแนนมาตรฐานของทุกตัวแปรเป็น Excel ข้อสอง ใน Excel สร้างคอลัมน์ใหม่ชื่อ LEAD_SUPP คูณคะแนนภาวะผู้นำกับการสนับสนุนทีละแถว สังเกตว่าตัวคูณนี้มีค่าเฉลี่ยประมาณ .77 และส่วนเบี่ยงเบนมาตรฐาน 1.51 ไม่ใช่ 0 กับ 1 เพราะสองตัวแปรสัมพันธ์กันสูง จำค่านี้ไว้ เดี๋ยวต้องใช้ตอนคำนวณ Simple slope และตัวคูณนี้หางหนักมาก ค่า kurtosis 42.7 ต้องเขียนเป็นข้อจำกัด ข้อสาม กลับเข้า ADANCO เลือก Import data… เปิดไฟล์ใหม่ ข้อสี่ สร้าง LEAD_SUPP เป็นตัวแปรที่มีตัวชี้วัดตัวเดียว แล้วลากเส้นเข้าบรรยากาศองค์กร ข้อห้า กด Run ตั้ง Bootstrap 5,000 รอบ ข้อหก เปิดตาราง Direct Effects Inference แล้วอ่านแถว LEAD_SUPP ไป ORGA
