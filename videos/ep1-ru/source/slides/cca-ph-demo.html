ขั้นที่ 2: สร้าง RU (Mode B) จากคะแนนทั้งสาม แล้ว Run

เดี๋ยวเราจะลองไปดูกันว่า หากกดด้วย ADANCO จะต้องทำยังไงบ้าง ตามหกขั้นบนจอเลย เริ่มจากเมนู Project เลือก Import data… แล้วเปิดไฟล์ข้อมูล ในไฟล์มีคะแนน 9 ด้านของครู 688 คน ต่อมาสร้างตัวแปรสามตัว ตรงนี้มีกับดักนิดหนึ่ง ต้องเลือก Emergent ไม่ใช่ Latent เพราะใน ADANCO คำว่า Emergent หมายถึงแบบประกอบ แล้วตั้งเป็น Mode B จากนั้นลากตัวชี้วัดเข้าแต่ละตัว ขั้นที่สาม เลือก Project › Conduct CCA/CFA หรือกด Ctrl+F ขั้นนี้ไม่ต้องลากลูกศรระหว่างตัวแปร เพราะเรายังถามแค่เรื่องการวัด ขั้นที่สี่ กด Run และตั้ง Bootstrap 3,000 รอบ Bootstrap คือการสุ่มครู 688 คนจากข้อมูลเดิมแบบใส่คืน ได้ข้อมูลชุดใหม่ 3,000 ชุด แล้วคำนวณซ้ำทุกชุด ค่าที่แกว่งไปมาระหว่างชุด คือที่มาของค่า t และช่วงเชื่อมั่น โดยไม่ต้องสมมติว่าข้อมูลแจกแจงปกติ ขั้นที่ห้า Export ผลเป็นไฟล์ HTML และเก็บคะแนนองค์ประกอบเป็น Excel ขั้นสุดท้ายคือรอบที่สอง สร้างการใช้ประโยชน์วิจัยแบบ Mode B จากคะแนนทั้งสามตัวนั้น แล้วกด Run อีกครั้ง ได้ผลแล้ว ไปดูกัน
