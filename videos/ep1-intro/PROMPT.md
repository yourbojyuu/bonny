ช่วยสร้างวิดีโอ **อินโทรแอนิเมชันเปิด EP1** (ยาวประมาณ 1:34 นาที ฉาก 1–7) ของซีรีส์ "Phuchit × ADANCO" เพื่อเอาไปต่อหน้า EP1 ที่ทำเสร็จแล้ว

## 1. อ่านก่อนเริ่ม (อยู่ใน repo `yourbojyuu/bonny` branch `claude/friendly-brahmagupta-l7eh5g`)

1. `CLAUDE.md` และ `videos/STYLE-GUIDE.md` — สไตล์ของผู้ใช้ (Gen-Z สดใสดุ๊กดิ๊ก, glassmorphism, ฟอนต์ Prompt + Anuphan, SFX เบาสุ่มไม่ซ้ำ, เสียงพากย์ผ่าน chain เดียว) ต้องคงความสอดคล้องกับ EP1
2. `videos/ep1-intro/STORYBOARD.md` — **storyboard ฉบับเต็มฉาก 1–7 ที่ผู้ใช้เขียนไว้ ถือเป็น spec** ห้ามแก้บทพูด (VO) ฉาก 1–4 แม้แต่คำเดียว คำว่า "วิทยานิพนธ์" ต้องใช้ทุกที่ (ห้ามใช้ "ปริญญานิพนธ์")
3. `videos/ep1-ru/` — โปรเจกต์ EP1 ต้นแบบ โดยเฉพาะ `scripts/` (build_frames.py, process_voice.py, make_sfx.py, make_preview.py, transcribe.py), `assets/fonts`, `assets/vendor/gsap.min.js`, `assets/sfx/v/` (พาเลตต์เสียงเอฟเฟกต์ + `palette.json`)
4. รัน `git fetch origin` แล้วอ่านบทเรียนรอบหลังใน `git show origin/claude/relaxed-wozniak-st8v81:videos/STYLE-GUIDE.md` (EP2: ทุกอย่างตรงกับคำพูด, ซูม, วงไฮไลต์, กับดักที่เจอแล้ว)
5. เริ่มงานด้วย skill `/hyperframes` (ตามที่ `videos/ep1-ru/CLAUDE.md` กำหนด) และเรียก skill ที่เกี่ยวข้องก่อนเขียน composition

- โปรเจกต์ใหม่ `videos/ep1-intro/` (1920×1080, 30 fps) คัดลอก `assets/fonts`, `assets/vendor`, `assets/sfx` จาก ep1-ru มาใช้ แล้วเขียน `index.html` + sub-composition ต่อฉาก (`compositions/scene-01.html` … `scene-07.html`)
- ไม่มีสไลด์ในเด็คสำหรับอินโทร จึง **วาดภาพเองทั้งหมดด้วย HTML/SVG/CSS + GSAP** (ต้อง seek-safe: ไม่ใช้ `Math.random()`/`Date.now()`) ให้ภาพเป็นสไตล์ flat/glass พาสเทลเดียวกับสไลด์ EP1
- ส่งไฟล์สุดท้าย: `renders/EP1-INTRO.mp4` คุณภาพสูง + สำเนาบีบอัดต่ำกว่า 100 MB ใน `deliverables/` แล้ว commit/push (branch ที่ระบบกำหนดให้ session นั้น)

## 3. ความสอดคล้องของสไตล์ (ต้องตรงกับ EP1)

- **ห้าสีของประกาย/อัญมณี**: น้ำเงิน `#1666E8`, ม่วง `#6A2EE8`, ชมพู `#F0508F`, ส้ม (เลือกส้มสดที่เข้ากับพาเลตต์ เช่น `#FF9F43`), ฟ้าเขียว `#22B8CF` — ใช้ชุดเดียวกันตลอดทุกฉาก

## 4. Motif ที่ต้องต่อเนื่อง (สำคัญที่สุดของงานนี้)

- **ตราหกเหลี่ยมบนปกเล่ม + ช่องเว้ากลมเล็กห้าช่อง** ต้องเป็นองค์ประกอบเดียวกันตั้งแต่ฉาก 1 (ว่าง มืด) → ฉาก 2 (เรืองริบหรี่ทีละช่อง) → ฉาก 4 (ประกายพุ่งออกจากช่อง) → ฉาก 6 (อัญมณีลอยกลับเข้าช่องเดิมของแต่ละก้อน ตำแหน่งและลำดับสีต้องตรงกับบนปกเล่ม)
- **ประกายห้าสี** เล็กตั้งแต่ฉาก 1 (ในดวงตาเล่ม) → ฉาก 3 (แสงรอดตามขอบหน้ากระดาษ) → ฉาก 4 (ดวงไฟจิ๋ว) → ฉาก 5 ขยายเป็นห้าอัญมณีผลึกหกเหลี่ยมในกรอบกระจก (ไม่มีป้ายชื่อ ห้ามใส่ชื่อตัวแปร) → ฉาก 7 ยังหรี่นิ่งรอคิว
- สร้างเป็น component เดียว (ฟังก์ชัน JS/SVG symbol) เรียกใช้ซ้ำทุกฉาก เพื่อให้ตรงกันเป๊ะ

## 5. เสียง

- **เสียงพากย์ (VO)**: บทอยู่ใน STORYBOARD.md ผู้ใช้ส่งไฟล์เสียงมาเอง ให้ขอไฟล์ตั้งชื่อ `EP1-INTRO-NN.mp3` (NN = เลขฉาก) ก่อนทำจังหวะจริง ถ้ายังไม่มีไฟล์ ให้ทำเวอร์ชันร่างโดยประมาณเวลาจากความยาวบทเทียบกับช่วงเวลาใน storyboard แล้วบอกผู้ใช้ชัดเจนว่ายังเป็นร่าง
- เมื่อได้ไฟล์เสียง: `process_voice.py` (tone match + loudnorm −16 LUFS + ตัดช่วงเงียบหัวท้าย/ย่อช่วงหยุดที่ยาวเกิน 0.7 วินาที) → `transcribe.py` (Whisper turbo ผ่าน sherpa-onnx ได้ `asr.json`) แล้วตั้งเวลาทุกภาพ/การ์ด/ประกาย/ซูมให้ **ตรงกับคำที่พูดจริง** ด้วยระบบ cue ใน `build_frames.py` (ใช้เลขวินาทีเมื่อ ASR ฟังไม่ชัด)
- เสียงเอฟเฟกต์ที่ storyboard ระบุ (นาฬิกาติ๊ก ๆ, ตึ่ง!, ป๊อก ป๊อก, กระดิ่งห้าโน้ต, ติ๊งของแต่ละแถบ EP, สั่นสะเทือนหนึ่งจังหวะ ฯลฯ) ให้สังเคราะห์เพิ่มใน `make_sfx.py` ตามหลักเดิม (เพนทาโทนิกเดียวกัน, ตัดย่านแหลม, สุ่มแบบสับไพ่ไม่ซ้ำติดกัน, เบากว่าเสียงพูดราว 13 dB)
- เพลงประกอบที่ storyboard ระบุ (เปียโนเบา ๆ ทีละโน้ต, เพลงเปลี่ยนจังหวะ, เพลงเร่งขึ้น, ดนตรีไต่ระดับตามแถบ EP): ผู้ใช้เคยบอกว่าจะใส่ BGM เองและไม่ให้แต่งเพลงพื้นหลัง → **ถามผู้ใช้ก่อน** ว่าต้องการให้สร้างแทร็กดนตรีสั้น ๆ ตามบทหรือเว้นแทร็ก 5 ไว้ให้ใส่เอง

## 6. ข้อที่ต้องถามผู้ใช้ก่อนลงมือ (อย่าเดา)

1. อินโทรนี้ต่อกับ EP1 อย่างไร: ฉาก 7 ตัดเข้า "สไลด์ 2" (ชื่อตอน) หมายความว่าอินโทรมาแทนสไลด์ปก (หน้า 1) และบทพูดหน้า 1 เดิมของ EP1 ("สมมติมีคนถามว่าครูในโรงเรียน…") หรือไม่ หรือต่อก่อนหน้า 1? (เนื้อหาซ้ำกันบางส่วน) และต้องการให้ต่อรวมเป็นไฟล์เดียวกับ EP1 หรือส่งเป็นไฟล์อินโทรแยก
2. ฉาก 7 "เงียบสนิทก่อนตัดเข้าเสียงพิธีกร" — ต้องเว้นช่วงเงียบกี่วินาที
3. ประโยค "ในฐานะครูคนหนึ่ง" ฉาก 3 ใช้ตามเดิมหรือผู้ใช้จะแก้
4. ไฟล์เสียงพากย์และ BGM (ดูหัวข้อ 5)
5. ป้ายหน้าจอ "ADANCO" ในฉาก 6 ใช้ภาพจำลองแนวเรียบ ๆ (วาดเอง) ไม่ใช่ภาพจริงของโปรแกรม ถูกต้องใช่ไหม

## 7. ขั้นตอนทำงานที่เวิร์กจาก EP1/EP2

1. ตั้งโปรเจกต์ → วาด component หลัก (เล่ม, ตราหกเหลี่ยม+ช่องห้าช่อง, ประกายห้าสี, อัญมณี, การ์ดกระจก) → ทำทีละฉาก
2. `npx hyperframes check` (ถ้า timeout ให้ `--range`) → `npx hyperframes snapshot --at ...` ดูภาพจริงที่จุดสำคัญของทุกฉาก (ตราหกเหลี่ยม/ช่องห้าช่อง/ประกายต้องเห็นชัดและตรงกันข้ามฉาก)
3. รอบแรกส่งภาพนิ่ง/ตัวอย่างสั้นให้ผู้ใช้ดูก่อน render เต็ม
4. render: `npx --yes hyperframes@0.8.184 render -o renders/EP1-INTRO.mp4` (วิดีโอ 17 นาทีใช้ ~80 นาที อินโทร 1.5 นาทีน่าจะราว 7–10 นาที) ตรวจเฟรมและความดังเสียงจากไฟล์ที่ได้
5. กับดักที่เจอแล้ว: `fromTo` ของสิ่งที่โผล่ทีหลังต้อง `immediateRender: false`, อย่าใส่ scale กับ element inline, SVG ไม่มี offsetLeft ให้เล็งที่กล่อง HTML ที่ห่อ, ใช้ id เดียวต่อ element ต่อ cue
6. commit/push ทุกครั้งที่จบขั้น (ไฟล์เรนเดอร์ใหญ่อยู่ใน `.gitignore` อยู่แล้ว ส่งให้ผู้ใช้ด้วยการแนบไฟล์)
