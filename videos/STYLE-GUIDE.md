# สไตล์วิดีโอที่ชอบ — ซีรีส์ "Phuchit × ADANCO" (สรุปจาก EP1)

ใช้เป็นจุดตั้งต้นของ EP ถัดไป โปรเจกต์ต้นแบบคือ `videos/ep1-ru/` (สคริปต์ทั้งหมดอยู่ใน `scripts/` นำกลับมาใช้ได้เลย)

## ภาพรวม
- วิดีโอสอนแนว YouTuber, 16:9 (1920×1080), อารมณ์ **สดใส happy, Gen Z, ดุ๊กดิ๊ก** ไม่แข็งทื่อ แต่เนื้อหายังอ่านง่าย
- ภาพหลักมาจาก **เด็คสไลด์ของผู้ใช้** (Claude Slides artifact) แปลงทีละหน้าเป็นฉาก ไม่แก้ข้อความหรือเลย์เอาต์บนสไลด์เอง
- ดีไซน์: glassmorphism การ์ดกระจกขาวขุ่น, พื้นไล่สีอ่อนฟ้า/ม่วง/ชมพู, ฟอนต์ **Prompt** (หัวข้อ) + **Anuphan** (เนื้อหา)
- สีหลัก: ฟ้า `#1666E8` / `#4C8DF8`, ม่วง `#6A2EE8`, ชมพู `#F0508F`, เหลือง `#FFC53D`, ฟ้าอมเขียว `#22B8CF`, ตัวอักษรเข้ม `#1A1F36`
- ป้ายบนปก: `SEM : Structural Equation Modeling` (ไม่ใช้รหัสวิชา ศ.ว.…)

## จังหวะ / โครงเรื่อง
- 1 หน้าสไลด์ = 1 ฉาก ความยาวตามเสียงพากย์ของหน้านั้น (เข้าเสียง 0.4s หลังฉากเริ่ม, ท้ายฉาก 0.6s, ฉากซ้อนกัน 0.6s) → ช่องว่างระหว่างเสียงพูดราว 0.4s ให้ลื่น ไม่ค้าง
- ทุกองค์ประกอบในหน้าต้องโผล่ครบภายใน ~5 วินาทีแรก (ไม่ปล่อยจอว่างนาน)
- เข้าฉากสลับ 3 แบบวนไป: ซูมเข้า / สไลด์จากขวา / ลอยขึ้น + กล้องค่อยๆ ดันเข้า 3% ตลอดฉาก

## ลูกเล่นการปรากฏ (ชอบมาก)
- **เมาส์ลากมาวาง**: การ์ดหลัก 2–3 ใบต่อหน้า ถูกเคอร์เซอร์สีขาวคว้าลากเข้ามาจากขอบจอ (เอียงนิดๆ) วางแล้ว **ยุบ-เด้ง** + **คอนเฟตติระเบิด** ตรงที่วาง (ห่างกันใบละ ~1.8s)
- การ์ดอื่น **เด้งแบบสปริง** (elastic) ส่ายเล็กน้อย, หัวข้อปาดเข้าจากซ้ายเด้งเกิน, เลขหน้าหมุนเด้ง
- **ดาวสติ๊กเกอร์** 4 ดวงสีสดผุดที่มุมจอทุกหน้า หมุน-ลอยเบาๆ, ลวดลายตกแต่งลอยขึ้นลง
- ตารางไล่ขึ้นทีละแถว, ตัวเลขใหญ่ **นับขึ้น**, ลูกศรในแผนภาพ **วาดทีละเส้น**

## เสียง
- **เกลี่ยเสียงพูดให้เหมือนอัดรอบเดียว**: ทุกไฟล์ผ่าน chain เดียวกัน (highpass 80 Hz, ลด 220 Hz −2.5 dB, เพิ่ม 3.2 kHz +2.5 dB, คอมเพรส 3:1, de-ess, loudnorm −16 LUFS, เฟดเข้า 0.04s/ออก 0.18s) — `scripts/process_voice.py`
- **เอฟเฟกต์หลายแบบ สุ่ม ไม่ซ้ำ ละมุนหู**: ชุดเสียง ~40 ตัว (ฟองอากาศ มาริมบา คาลิมบา ติ๊ก วูบ ประกาย ระฆัง) จูน **เพนทาโทนิกเดียวกัน**, ตัดย่านแหลม, เลือกแบบสับไพ่ (ใช้ครบก่อนซ้ำ ไม่ซ้ำติดกัน) + สุ่มความดัง ±15% — `scripts/make_sfx.py`
- จุดใส่เสียง: เปลี่ยนหน้า=วูบ, คว้า=ติ๊ก, วาง=ป๊อป/มาริมบา, การ์ดเด้ง=ฟองอากาศ, ตัวเลขนับเสร็จ=คาลิมบา, ดาวผุด/คอนเฟตติหน้าสำคัญ=ประกาย, สรุปผล=ระฆัง, เปิดปก=เบสนุ่ม
- **ไม่แต่งเพลงพื้นหลังเอง** — ผู้ใช้ใส่ BGM เอง (เว้นแทร็ก 5 ใน `index.html`, แนะนำ volume ~0.12 ใต้เสียงพูด)

## คลิปสาธิตหน้าจอ (ADANCO)
- ก่อนเข้าคลิป: สไลด์หน้าสาธิต → **เมาส์คลิกปุ่มเล่น** (วงกระเพื่อม) → กรอบ **ขยายเต็มจอ** → เล่นคลิป → **เฟดเข้าหน้าถัดไป**
- แสดง **เต็มเฟรม ไม่ซูม ไม่บัง** อยากเห็นแถบเมนูตอนกด → ต้องได้ไฟล์อัดจอที่ **ไม่ครอปขอบบน** (Mac = 16:10 แสดงแบบ contain)
- ตัดต่อให้กลมกล่อม: ช่วงเงียบ >1.4s (คลิก/รอ) **เร่ง 2–8 เท่า** แทนการตัดทิ้ง ช่วงพูดเล่นปกติ — `scripts/edit_clip.py` (ต่อด้วย PCM เพื่อกันเสียงเลื่อนจากภาพ)
- เสียงในคลิปผ่าน chain เดียวกับเสียงพากย์ + ลดเสียงรบกวน แล้วเล่นเป็นแทร็กแยก (วิดีโอ muted)

## ขั้นตอนทำงานที่เวิร์ก
1. ไฟล์เสียงพากย์แยกรายหน้า (`EP?-…-NN.mp3`) + ยืนยันการจับคู่ไฟล์ ↔ หน้า ก่อนสร้าง
2. `edit_clip.py` → `process_voice.py` → `make_sfx.py` → `build_frames.py` → `npx hyperframes check` → snapshot → render
3. ไฟล์ใหญ่ (คลิป) ส่งผ่าน GitHub (push ด้วย GitHub Desktop, ไฟล์ <100 MB) — sandbox โหลดจาก Google Drive ได้แค่ไฟล์ <10 MB
4. ส่งวิดีโอที่บีบให้ <100 MB ไว้ใน `deliverables/` (render เต็มใช้ ~1 ชม.)
