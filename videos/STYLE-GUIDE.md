## ภาพรวม
- วิดีโอสอนแนว YouTuber 16:9 (1920×1080) อารมณ์ **สดใส Gen Z ดุ๊กดิ๊ก** แต่อ่านง่าย
- ภาพหลัก = **เด็คสไลด์ของผู้ใช้** (Claude Slides artifact `https://claude.ai/artifact/K8CmGMY9XoxP4J8HcDecxA`) 1 หน้า = 1 ฉาก **ห้ามแก้ข้อความ/เลย์เอาต์บนสไลด์**
- ดีไซน์ glassmorphism, ฟอนต์ Prompt (หัวข้อ) + Anuphan (เนื้อหา), สี ฟ้า `#1666E8`/`#4C8DF8` ม่วง `#6A2EE8` ชมพู `#F0508F` เหลือง `#FFC53D` ฟ้าอมเขียว `#22B8CF` ตัวอักษร `#1A1F36`
- ลำดับสไลด์ในเด็ค (`project/deck.json` → `order`): EP1 = หน้า 1–16 (`cover`…`cca-ph-sum`), EP2 = 17–35 (`ep2`…`sem-ph-sum`), **EP3 = 36–50** (`ep3`, `mm-idea`, `mm-mod-rule`, `mm-ph-why`, `mm-ph-compare`, `mm-ph-mod-demo`, `prn-mm-result`, `mm-tab-result`, `mm-ph-slopes`, `mm-tab-src`, `mm-tab-sum`, `mm-ph-sum`, `review`, `summary`, `finale`)

## จังหวะ
- ความยาวฉาก = เสียงพากย์ของหน้า (เข้าเสียง 0.4s, ท้าย 0.6s, ฉากซ้อน 0.6s; หน้าสุดท้ายค้าง 4.5s)
- เข้าฉากสลับ 3 แบบ (ซูม / สไลด์จากขวา / ลอยขึ้น) + กล้องดันเข้า 3% ตลอดฉาก
- **ทุกอย่างตรงกับคำพูด** (เพิ่มใน EP2; EP3 ใช้เวลาจริงจาก ASR `scripts/words/*.json` จับคู่กับข้อความทีละตัวอักษร แทนการประมาณ): การ์ดโผล่/ถูกลากวาง, กล้องซูม, วงไฮไลต์, ลูกศรวาด เกิดตอนที่พากย์พูดถึงคำนั้น กำหนดใน `CUES` ของ `scripts/build_frames.py` (ไม่มี ASR ใน sandbox → ประมาณเวลาคำจากข้อความใน `SCRIPT.md` กระจายบนช่วงที่มีเสียงพูด)

## ลูกเล่น
- **เมาส์ลากวาง**: เคอร์เซอร์ขาวลากการ์ดเข้าจากขอบจอ วางแล้วยุบ-เด้ง + คอนเฟตติ (ห่างกัน ≥1.8s)
- การ์ดอื่น **เด้งสปริง**, หัวข้อปาดเข้า, เลขหน้าหมุนเด้ง, ดาวสติ๊กเกอร์ 4 ดวงที่มุมจอ, ลวดลายลอย
- **กล้องซูม (punch-in)** เข้าจุดสำคัญตอนพูดถึง ค้าง 2–8s แล้วถอยกลับ (ตาราง, ภาพหน้าจอทีละภาพ, ตัวเลขผลลัพธ์)
- **วงไฮไลต์** สีสลับ เหลือง/ชมพู/ฟ้า รอบแถว/ตัวเลข/คำ + ดาวเล็ก
- ตารางไล่ขึ้นทีละแถว, ตัวเลขใหญ่นับขึ้น (รวมทศนิยม/%), ลูกศรวาดทีละเส้น: **เส้นยืดออกจากจุดเริ่ม หัวลูกศรวิ่งไปกับปลายเส้น** (ห้ามมีหัวลูกศรรอที่ปลายก่อน)

## เสียง
- เสียงพากย์ทุกไฟล์ผ่าน chain เดียวกัน (`scripts/process_voice.py`, loudnorm สองรอบ −16 LUFS ทุกไฟล์เท่ากัน)
- **กระชับ** (EP3): ช่วงหยุด >0.38s ตัดเหลือ 0.30s, เร่ง 1.07× (คงระดับเสียง); เสียงในคลิปบีบไดนามิกเพิ่ม + EQ ให้โทนตรงกับเสียงพากย์
- **SFX หลายแบบ สลับไม่ซ้ำ ไม่รบกวน**: 63 เสียง 14 หมวด จูนเพนทาโทนิกเดียวกัน (`scripts/make_sfx.py`), สับไพ่ไม่ซ้ำติดกัน, ความดังสุ่ม ±15%, รวมแล้วเบากว่าเสียงพูด ~13 dB
- จุดใส่: เปลี่ยนหน้า=วูบ, คว้า=ติ๊ก, วาง=ป๊อป/มาริมบา/คาลิมบา, ซูมเข้า/ออก=ลมพัดขึ้น/ลง, ไฮไลต์=กระดิ่งแก้ว, ลูกศร=เสียงปากกา, นับเลขเสร็จ=คาลิมบา, สรุป=ระฆัง
- **ไม่ใส่เพลงพื้นหลัง** — เว้นแทร็ก 5 ใน `index.html` ให้ผู้ใช้ใส่เอง (~0.12)

## คลิปสาธิต ADANCO
- หน้าสาธิต: กรอบคลิปเล่น **พรีวิวตัดต่อจากคลิปจริง** (ซูมช้า, ชิป PREVIEW, แสงกวาด, ปุ่มเต้น) ไม่ใช่กรอบรอว่าง → พากย์สั้น → เมาส์คลิกปุ่มเล่น → กรอบขยายเต็มจอ → สไลด์+ดาว **หายไป ไม่บังคลิป** → เล่นคลิป → เฟดเข้าหน้าถัดไป
- `scripts/edit_clip.py`: ช่วงเงียบ >1.4s เร่ง 2–8 เท่า (EP2: 17:45 → 12:11), เสียงคลิปผ่าน chain เดียวกัน เล่นเป็นแทร็กแยก
- EP3 เข้มขึ้น: เงียบ ≥0.8s เหลือ ~0.6s (สูงสุด 12×), ช่วงพูด 1.08× (13:49 → 8:25); หน้าที่ยังไม่มีเสียงพากย์ค้างแค่ 7–16 s ไม่ปล่อย dead air

## ไฟล์และการรับส่ง (สำคัญ ประหยัดเวลา)
- เสียงพากย์: Google Drive โฟลเดอร์ของตอน ชื่อ `EP?:XXX-NN.mp3` (NN = ลำดับหน้าในตอน) — ดึงด้วย Drive connector ได้ (<10 MB/ไฟล์), ผลถูกบันทึกเป็นไฟล์ JSON base64 → ถอดด้วย `jq -r .content | base64 -d`
- คลิปสาธิต (>10 MB): **Drive ดึงไม่ได้ และเว็บ GitHub อัปได้แค่ 25 MB** → ผู้ใช้วางไฟล์ใน `videos/<ep>/assets/video/<ชื่อ>.mp4` แล้ว commit + push ด้วย **GitHub Desktop** (ติ๊กเฉพาะไฟล์คลิป ไม่เอา `.DS_Store` หรือไฟล์ลงท้าย ` 2` ที่ iCloud สร้าง) — ต้องสร้างโฟลเดอร์ `assets/video/` (มี README.txt) ไว้ก่อน
- ภาพหน้าจอในสไลด์ (`/_blob/<id>`): อ่านทีละไฟล์ด้วย Artifact `read` + `path=<id>` → `assets/img/<id>.png`
- ไฟล์เสียงหน้าที่สั้นผิดปกติ: ถามผู้ใช้ก่อน (EP2 หน้า 19 สั้นโดยตั้งใจ)
- **ไฟล์เสียงไม่จำเป็นต้องตรงหน้าตามเลข** (EP3: 05/06 สลับ, ไฟล์เดียวครอบสองหน้า, บางหน้าไม่มีเสียง) → ฟังก่อนด้วย whisper-small จาก npm (`videos/ep3-mm/scripts/transcribe.mjs`; Hugging Face ถูกบล็อก แต่แพ็กเกจ npm `sts-whisper-small` มีโมเดลมาในตัว) แล้วแก้ข้อความใน `SCRIPT.md` ให้ตรงกับที่พูดจริง
- จับคู่หน้า↔ไฟล์ และจุดตัดไฟล์ที่ครอบหลายหน้า อยู่ในตาราง `VOICE` ของ `scripts/process_voice.py` (EP3); หน้าที่ยังไม่มีเสียงจะค้างเงียบตามความยาวข้อความโดยประมาณ

## ขั้นตอน
1. ดึงสไลด์ของตอน → `source/slides/`, เสียง → `source/audio-raw/`, เขียน `SCRIPT.md` (`## pNN …` บรรทัดถัดไปคือคำพากย์)
2. ตั้ง `SLIDES`, `FIRST/LAST/DEMO`, ชื่อไฟล์คลิป และ `CUES` ใน `build_frames.py`

4. เตือนที่ยอมรับได้: ตัวอักษร <28px (ดีไซน์สไลด์), line_unread ตอนกรอบคลิปขยาย, first_frame_empty, คอนทราสต์ป้ายเล็กในสไลด์

## กับดักที่เจอแล้ว (แก้ไว้ในสคริปต์ EP2)
- GSAP `fromTo` ของคอนเฟตติ/วงกระเพื่อมต้อง `immediateRender: false` ไม่งั้นโผล่ก่อนเวลา
- อย่าใส่ scale กับ element inline (`<b>`) — คำกระโดดไปท้ายบรรทัด
- SVG ไม่มี offsetLeft → เล็งเมาส์ที่กล่อง HTML ที่ห่อ SVG
- ตารางในสไลด์ส่วนใหญ่เป็น CSS grid ไม่ใช่ `<tr>` → แถวไฮไลต์รวมเซลล์ที่อยู่บรรทัดเดียวกัน
- element เดียวถูกหลาย cue → ใช้ data-z id เดียว
- วงไฮไลต์บนคำตัวหนา (`<b>`) ที่ขึ้นบรรทัดใหม่ → กรอบเพี้ยน ให้วงทั้งประโยค/ย่อหน้าแทน
- คำใน cue ต้องไม่ซ้ำกับคำที่พูดก่อนหน้า (EP3: "และสาม" ไปเจอ "และสามรูปแบบ" ก่อน) ใช้วลีให้ยาวพอ
